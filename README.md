# Diamond Hotel, Restaurant & Event Management

Premium responsive restaurant/hotel website built as a Vite + React single-page site.

## Animation approach
The design follows the public Animmaster component-first philosophy and uses Animmaster-compatible `data-anim-*` hooks for the marquee area, plus purposeful CSS motion for hero/reveal/hover effects. The paid Animmaster component source itself is not included because it was not provided.

Public references:
- https://animmasterlib.dev/
- https://animmaster.github.io/docs/workcomponent.html

## Run
npm install
npm run dev

## Build
npm run build
